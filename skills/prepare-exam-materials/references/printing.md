# 本番PDFと検証

## 設定と出力

本番は日本語、JIS B4縦257×364mm、2段組。別マークシートを使うため、問題ごとの解答欄はない。試験名・注意事項・初稿ラベルを本文上部へ追加しない。試験名や条件は学校フッター内へ入れる。

`exam.json`の`footer`には`subject`（科目）、`class_name`（組）、`author`（出題者）、`term`（前期/後期/空文字）、`period`（時限）、`allowed_materials`（持込条件）、`submission`（氏名欄へ印字する提出に関する指定、通常は空文字）を指定する。`course_type`（必/選/空文字）は任意。氏名・番号・得点は学生/教員の記入用の欄として残す。日時と時間は試験入力から、ページ番号と総枚数は組版結果から入れる。過去の日時・60分・組・2枚を流用しない。

`assets/school-footer.json`は学校書式の罫線・固定項目名・空欄の座標だけを持つ。元のExcel/PDFには試験値が含まれるため、元ファイルを配布資産へコピーしない。学校指定位置は全ページで次のとおり。

| 左余白 | 下余白 | 幅 | 高さ |
| --- | --- | --- | --- |
| 28.9235659mm | 16.0076591mm | 200.3993595mm | 31.3655062mm |

PDFの左下原点ptでは`[81.9880609, 45.3760415, 650.0492375, 134.2861377]`。B4にしただけでは配置は保証されない。元のExcel書き出しPDFをそのまま合成せず、この領域へ罫線と文字を配置する。

Python 3、ReportLab、pypdf、日本語TrueTypeフォントを使う。既定フォントはmacOSのArial UnicodeとMenlo。なければ`--font`と`--code-font`で明示し、欠字がないことを確認する。リポジトリ直下から実行する。

```sh
python3 skills/prepare-exam-materials/scripts/build_exam_pdf.py \
  --exam "$EXAM_WORK/exam.json" \
  --questions "$EXAM_WORK/final.json" \
  --output "$EXAM_WORK/final-v1.pdf" \
  --render-dir "$EXAM_WORK/final-v1-pages"
```

入力形式は[出題手順](authoring.md)と共通だが`purpose`は`final`、問数は本番数、日本語だけでよい。PDFには正答・解説を出さない。本番正答は元JSONの問題番号・選択肢順で教員が参照する。生成器は本番の順序を変えない。順番を調整したら入力を改版し、正答表との対応を再確認する。

問題を途中で分割せず、必要なページ数を求めてから全ページの枚数欄を埋める。1問が段に収まらない、コード行が長過ぎる、フッター欄に入らない、フォントに字がない場合は失敗する。字を小さくして無理に詰めず、問題文・コード・表記を見直す。

PDFの横へ`.layout.json`も生成する。問題の位置とフッター領域・ページ数の記録であり、これも教員用の非公開領域に置く。任意の`--render-dir`には追加でPyMuPDFが必要で、全ページの画像と、PDFから読み取ったフッター罫線のbbox・枚数欄の検算結果を記録する。生成器の成功を目視済みという意味にしない。

## 全ページの確認

1. 問数・番号・4択・正答表・配点を入力と照合する。配点未指定なら点数を載せない。指定時は本番数×各問配点＝総点を確認する。
2. PDFの実ページ寸法を調べる。さらにPDFの罫線の実位置を読み取り、上のbboxと照合する（`scripts/test_exam_pdf.py`のPyMuPDFによる検算が例）。設定JSONの数値だけを見て成功としない。
3. 全ページを画像化する。例：`pdftoppm -scale-to 1800 -png "$EXAM_WORK/final-v1.pdf" "$EXAM_WORK/final-v1-page"`。Popplerがなければ利用可能なPyMuPDFで全ページをレンダリングする。
4. 各ページで文字欠け、コードの改行/字下げ、問題や選択肢のはみ出し・分断、段順、フッターの重なり、固定位置、ページ番号/総枚数を目視する。フッターは拡大して学校書式と照合する。
5. 確認対象のSHA-256、全ページの確認結果、修正点と未確認を非公開作業記録へ残す。本番の相談・確定はこの版を示して進める。

印刷機による実寸出力はPDF検証とは別。実際に印刷する教員には、用紙JIS B4・倍率100%で学校フッター位置を確認してもらう。未実施を印刷確認済みとはしない。
