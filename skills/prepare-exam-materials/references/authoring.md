# 出題・翻訳・復習HTML

## 先に配分を相談する

配布版と各単元の教員ガイド「この単元の教材方針」を読む。READMEの教材方針に沿って、基本事項、根拠の単元/節、本番の問数、復習の問数、空欄/説明などの配分を表で提案する。単元数・20基本事項・空欄10＋説明10・20問/40問を固定しない。

各問に、基本事項を表す`topic`と、その版の根拠を付ける。選択肢は4個で、表記だけでなく内容も唯一正解か確認する。短くやさしい日本語を使い、コードの読み取りを難しい漢字や長文の読解へ置き換えない。

復習と本番は別々の問題ファイルにする。同じ基本事項を問うが、問題文・場面・コード例・問い方・選択肢を独立して作る。比較表で次を点検し、非公開の作業記録へ残す。

- 変数名・数値だけを変えたコピーになっていないか
- 本番の他の問題や選択肢が、別問の正答を直接教えていないか
- 全問の根拠が配布版と範囲にあり、狙った配分と一致するか
- 正答の理由と、残り3択が誤りになる理由が成立するか

付属HTMLの新経路は全プールから指定数を無作為抽選する。1回ごとの事項別配分は固定しない。全事項を毎回必ず出すなどの抽選配分を依頼された場合は、その条件を記録して対応する。既存中間問題集専用の「各事項から1問、空欄半数」の規則をそのまま適用しない。

## 入力形式

復習用JSONのトップレベルは`purpose: "practice"`、本番用は`purpose: "final"`。`questions`は次の形の配列。これは架空の構造例で、実試験の問題ではない。

```json
{
  "purpose": "practice",
  "questions": [{
    "id": "practice-01",
    "topic": "計算",
    "kind": "explain",
    "prompt": "この式の結果を選んでください。",
    "code": "2 + 3",
    "choices": ["4", "5", "6", "7"],
    "answer": 1,
    "explanation": "2に3を足すと5です。",
    "source": "docs/example/index.html#addition",
    "translations": {}
  }],
  "ui": {}
}
```

`answer`は表示ラベルではなく元の選択肢のindex（0〜3）。順番を変えてもこの対応を保つ。`code`は省略可、`kind`は記録用。問題数は試験設定の値と一致させる。`translations`には日本語以外の配布言語を漏れなく入れ、それぞれに`prompt`・`choices`（同じindex順）・`explanation`を持たせる。コードは共通で翻訳しない。文中コードはバッククォートで囲む。出典は学生の教材の`docs/…html#見出し`を使い、個別のClassroom IDや教員ローカル絶対パスを入れない。

## 翻訳

[翻訳スキル](../../translate-teaching-materials/SKILL.md)の用語集、コード・画面語の保護、原文との独立照合を使う。対象言語は現在mainの`distribute`一覧ではなく**今回確定した配布版**の一覧。別版のカタログを丸ごと当てない。再利用は原文・用途・コードが同じ文に限り、変えた問題とUIを照合する。

通常の教材翻訳PRで行う`sync`を現在のmainに対して実行すると別版になる。試験の文は非公開作業領域で訳し、既存用語集を参照する。翻訳スキルの「PRへ照合結果を残す」は公開教材の手順なので、本番・比較表・個別IDを含む記録には適用せず、非公開記録へ残す。翻訳した担当とは別のモデルに資料を読ませ、指定の言語では原文を見せず訳し戻してから比較する。修正した訳も再照合する。

## 生成

リポジトリ直下から実行する。`EXAM_WORK`は確認済みの教員用非公開フォルダを指す。生成物は公開承認前のローカル版であり、Driveへ保存するコマンドではない。

```sh
python3 skills/prepare-exam-materials/scripts/build_practice.py \
  --exam "$EXAM_WORK/exam.json" --print-ui-template

python3 skills/prepare-exam-materials/scripts/build_practice.py \
  --exam "$EXAM_WORK/exam.json" \
  --questions "$EXAM_WORK/practice.json" \
  --output "$EXAM_WORK/practice-v1.html"
```

最初のコマンドでUIの日本語テンプレートを取得する。非日本語のUIは`ui.<言語コード>`へ入れる。数・日時などのプレースホルダーを保持して翻訳する。意味の違う古い日付や「各5点」を既存UIから持ち込まない。

生成器は既存`midterm-distribution.html`の単体方式を再利用する。`build-midterm-distribution.py`、`generate-midterm-practice.py`と`generate-midterm-pdf.py`は既存中間問題集専用のままなので、新試験のために実行しない（公開教材の書き換えや旧固定条件を避ける）。標準の題名は「中間テスト対策問題集」または「期末テスト対策問題集」。

## 動作確認

AGENTS.md §7の作業用プロファイルのheadless Chromeで、生成した**今回の**HTMLを確認する。

- オフラインで開始でき、本番数・復習数・抽選数・案内文が入力と合う
- 問題順・選択肢順が変わっても、正答・誤答・未回答を正しく採点する
- 回答途中と採点後に言語を切り替えても、回答・順序・結果が変わらない。日本語併記、コード、解説、出典も確認する
- 再挑戦で回答を消し、指定数を重複なく選び直す。時間制限を使う場合は終了時の採点も確認する
- 各言語の問題・選択肢の対応、文字欠け・横はみ出しを確認する

自動検査は件数・型・indexなどを保証する。内容上の唯一正解・適切な訳・出題範囲・復習と本番の独立性は、資料と照らすレビューで別に確認する。
