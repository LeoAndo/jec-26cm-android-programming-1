# 入力と配布版の確定

## 初回設定

`assets/local-settings.example.json`を、Git管理外・学生と共有されない教員のローカルフォルダへコピーして埋める。これは運用の設定で、生成器に外部サービスへの書き込み機能はない。空のIDを実在すると解釈しない。

- アカウント、対象コース、教材トピック、復習の投稿先トピック
- 学校Driveのmaterialsフォルダ、教員用の非公開保存先
- 学校フッターの科目・組・出題者・前後期・時限・持込条件・提出欄
- 必要なときだけ既存投稿ID・添付ファイルID（更新でコメントを保持するため）

保存先は実際の共有状態を確認する。リポジトリ外であってもDrive同期領域や学生と共有されたフォルダなら本番を置かない。生成器の`private_output`はGit内への誤出力を止めるが、共有権限までは判定しない。設定値を生成HTMLや公開用のログへ埋め込まない。

## 毎回の入力

| 項目 | JSONキー | 条件 |
| --- | --- | --- |
| 中間／期末 | `exam_type` | `midterm` / `final` |
| 試験日時 | `exam_datetime` | ISO 8601日時（例：2030-02-01T10:00:00+09:00） |
| 試験時間 | `duration_minutes` | 1以上の整数、分 |
| 出題範囲 | `scope` | 単元・節の文字列配列 |
| 解答形式 | `answer_format` | 付属生成器は`four_choice`のみ |
| 本番問題数 | `exam_count` | 1以上の整数 |
| 復習問題数 | `practice_count` | 省略時、本番の2倍。変更可 |
| 1回の復習で出す数 | `draw_count` | 省略時、本番数と復習数の小さい方。復習数以下 |
| 言語 | `languages` | 配布版にある`code`と`name`の配列。日本語を含む |
| 配点 | `points_per_question`, `total_points` | 任意。均等配点。総点は本番数×配点と照合 |
| 学校フッター | `footer` | 初回設定に今回の変更を反映。[印刷](printing.md)参照 |

配点を指定しないと復習は正答数で採点し、本番用紙に点数を印字しない。総点だけから各問の配点を推測しない。不均等配点を依頼された場合は各問の点数を確認する。付属生成器では未対応なので、均等配点へ勝手に変えず、生成器の対応が必要なことを伝える。

安全な入力例は`assets/exam.example.json`。これは架空の日時・範囲であり、そのまま試験を作る指示ではない。実際のJSON・問題・作業記録はすべて非公開保存先で管理する。

## 参照教材の確定

利用可能なコネクタ/APIの機能を発見して優先する。Classroomの必要な読み取り・添付確認に不足があれば、利用可能なCUAのドキュメントに従う。存在しないAPIや固定ブラウザIDを仮定しない。

1. 対象アカウント・コースを照合する。教材トピックの公開済み資料と添付の実体を確認する。下書き、別クラス、古いZIPへの新しい案内を区別する。
2. 添付ZIPまたはリンク先の実際の版を取得し、ZIPの版表示、収録単元・節、言語入口と収録言語を照合する。リンク先が更新され得る場合は取得した実体のSHA-256を記録する。
3. 出題範囲がその版に含まれるか確認する。配布されていない単元をmainから補わない。複数資料を併用するなら、単元ごとにどの版を使うか明示する。候補を絞れなければ確認待ちにする。
4. 作業記録へコース/トピック、投稿ID/URLと状態、添付ID/名前、版、取得時刻、SHA-256、収録範囲・言語、ローカル参照先、選定理由を残す。これは教員用記録で、問題HTMLの出典には教材の相対パスと見出しだけを載せる。

## 再開の記録

1試験につき非公開フォルダを作り、`work-record.md`に次を残す。

- 入力の確定値と保留事項、参照教材と根拠
- 基本事項と出題配分、問題ごとの出典（版・ファイル・見出し・根拠コード）
- 復習/本番それぞれのファイル名・SHA-256・生成日時、検証対象の版と結果
- 復習の状態：作成中／検証済み／公開前確認待ち／公開済み
- 本番の状態：作成中／検証済み／本番確認待ち／確定
- 公開確認に示した一式と承認の内容・対象・時刻、実際の投稿/添付確認結果

内容を変えたら新しい版として保存し、影響する検査と承認だけをやり直す。復習の公開済みという事実から、本番の確定を推測しない。
