ANDROID PROGRAMMING 1 / 共通資料・授業サポート

教員用ガイド
HelloAndroid

授業内で「操作・確認・言語化」まで終えるための進行案です。1コマ90分、全2コマを目安に、クラスの進み具合に合わせて調整します。

1. 授業前の準備

  • 教材フォルダ docs を一式配布します。HTML単体では画像や共通スタイルが欠けるため、フォルダ構成を保ちます。
  • 学生のMacで docs/hello-android/index.html をブラウザで開けることを確認します。公式資料以外にCDN・Webフォント・オンライン実行環境は使いません。
  • Android Studio Panda 2 | 2025.3.2、必要なSDK・System Image・Gradle依存関係を事前にそろえます。初回ダウンロードは下表の授業時間に含めません。
  • Panda2JavaEmptyViewActivity を出発点の見本として用意します。学生は同じJava / Empty Views Activityで A01HelloAndroid を新規作成します。
  • 配布済み完成版から始める場合は複製を開き、教材の code/01-MainActivity.java と code/01-activity_main.xml で、対応する2ファイルだけを戻します。教材本文のSTEP 1にも案内があります。
  • 指定エミュレータ jec_26cm_android1_Pixel 9a で完成版をRunし、文字変更・Snackbar・Toast・Logcatを確認します。
  • 本日の停止位置、APK提出の有無、提出先、ファイル名を板書します。

3. 留学生・初心者への進め方

  • 最初に完成動作を見せる。 1回の実演は「起動 → 変更 → 1 → 消えるのを待つ → 2」の順。操作と結果を同じ短い文で繰り返します。
  • 1回の指示は1つ。 「MainActivity.javaを開く」「importの下を見る」「2行追加する」と分けます。複数のファイルを同時に修正させません。
  • コード入力と意味の説明を分ける。 コピー後に、id・変数・処理の場所を指さして確認します。書き写しだけで完了とせず、予想と小変更で理解を見ます。
  • 英語のUI名を残す。 実画面と同じ表記を読み、日本語の短い意味を添えます。日本語の長い説明を暗記させません。
  • 止まれる場所を共有する。 各ステップの緑の確認欄で全員を待ちます。完成した学生は隣の画面を見て説明し、相手のキーボードを代わりに操作しないようにします。
  • 質問を定型にする。 「STEP __」「ファイル名」「赤い最初の行」。日本語で長く話せない場合は指さしや母語のメモから始められます。
  • 復習を授業内に置く。 STEP 8・9を必須とし、予習や自宅でのやり直しを前提にしません。

5. 到達度の確認

観点授業内で確認する証拠

場所が分かるXMLのidとJavaのfindViewByIdの対応を1つ示す。
変更の意味が分かるSTEP 8の変更で何が変わったか、短い文か指さしで説明する。
次に再開できるできたSTEPと困っている場所を記録する。

3のボタンに処理がないのは完成版の仕様です。画面再作成後の文字の保存はこの単元の対象に含めません。起動状態を確認するときはStop → Runで条件をそろえます。

チェックの保存はブラウザのlocalStorageを使い、送信はしません。ブラウザ・ファイルの移動・保存設定で記録が消える場合があるため、成績や提出の記録には使わず、STEP 9の記録を回収してください。

6. 教材の保守と確認

  • アプリを変更したら、本文の部分コード、完成コード、再開用コード、画像、練習の答えをまとめて確認します。
  • アプリ画像は教員の jec_26cm_android1_Pixel 9a で撮影します。画像は出発点、STEP 3、完成版の起動直後、変更後、Snackbar、Toastの6状態です。
  • 新規プロジェクト作成の3画像は教員提供資料を使用しています。
  • 印刷時は補足・解答も展開されます。解答を配布したくない場合は、ブラウザで授業中に開く方式を使ってください。
