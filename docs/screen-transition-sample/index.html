A01〜A05では、1つの画面（MainActivity）の中でアプリを作りました。今回は2つ目の画面 TestActivity を追加し、ボタンで画面を切り替えます。そのとき、次の画面へ値を渡します。受け取った値は画面には表示せず、A03・A05でも使った Logcat で確かめます。

できるようになること

STEP 04 · 目安 15分

Test 1で画面を切り替える

変更するファイル：MainActivity.java

Intent（インテント） は、「この画面を開きたい」というお願いをAndroidに伝える入れ物です。まずTest 1で、値を入れずに画面を切り替えます。STEP 5からは、この入れ物に値も入れて渡します。

① onCreateの中に追加

ひな形の });（return insets; の下）の下に、1行空けて追加します。

追加 · onCreateの中、ひな形の });の下
findViewById(R.id.btn1).setOnClickListener(v -> {
    var intent = new Intent(this, TestActivity.class);

importは android.content.Intent です。

コード意味
findViewById(R.id.btn1).setOnClickListener(v -> { … })btn1を見つけて、押されたときの処理を登録する。あとで使わないので変数には入れず、見つけた部品に続けて書く。A02 STEP 4の btnStart = findViewById(R.id.btn_start); と同じで、(Button) のようなキャストはいらない。

開いたTestActivityは、MainActivityの上に重なって表示されます。戻る操作をすると上のTestActivityが閉じ、下にあるMainActivityがまた見えます。

A04 STEP 8では、WebViewの中のページを戻す処理を自分で書きました。画面（Activity）を戻す動きはAndroidが行うので、今回はコードを書きません。

照合用 · MainActivity.java
package jp.ac.jec.a06screentransitionsample;

import android.content.Intent;
import android.os.Bundle;

import androidx.activity.EdgeToEdge;
import androidx.appcompat.app.AppCompatActivity;
import androidx.core.graphics.Insets;
import androidx.core.view.ViewCompat;
import androidx.core.view.WindowInsetsCompat;

public class MainActivity extends AppCompatActivity {

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        EdgeToEdge.enable(this);
        setContentView(R.layout.activity_main);
        ViewCompat.setOnApplyWindowInsetsListener(findViewById(R.id.main), (v, insets) -> {
            Insets systemBars = insets.getInsets(WindowInsetsCompat.Type.systemBars());
            v.setPadding(systemBars.left, systemBars.top, systemBars.right, systemBars.bottom);
            return insets;
        });

        findViewById(R.id.btn1).setOnClickListener(v -> {
            var intent = new Intent(this, TestActivity.class);
            startActivity(intent);
        });
    }
}

② 受け取ってLogに出す（Bの場所）

onCreateの中の、ひな形の }); の下に、1行空けて追加します。

コード意味
getIntent()この画面を開いたときのIntentを取り出す。Test 1なら、STEP 4でMainActivityが作ったIntent。
getIntExtra(EXTRA_KEY_INT_VALUE, 0)キー "intValue" のintを取り出す。入っていなければ、2つ目に書いた0を返す。

Log.d("TestActivity", "intValue: " + intValue)名前と値をつなげてLogcatに出す。A03 STEP 8・A05 STEP 5と同じ。タグはTestActivity。

2つ目に書いた値を 既定値（きていち） と呼びます。キーが入っていないときに返る値です。null（ヌル） は、何も入っていないことを表す値です。

ほかの型も同じ形で取り出せます

Intentには long や boolean なども入れられます。取り出すメソッドの名前が getLongExtra、getBooleanExtra のように変わるだけで、使い方は同じです。この単元では int と String の2つで仕組みを確かめます。

var は右側から型が決まります（A01 STEP 4）。getIntExtra なら intValue は int、getStringExtra なら stringValue は String です。

解説：キーの定数が、なぜ受け取る側のTestActivityにある？

② キーの文字を書くのは1か所"intValue" と書くのは定数の行だけ。入れる側と取り出す側で綴りがずれない。A04 STEP 5の「enumを使うメリット」と同じ考え方。
③ 開く側はキーを知らなくてよいMainActivityはstartに値を渡すだけ。どんなキーで入れるかは、受け取るTestActivityが決める。
④ 渡す値の型と順番をstartが決める型や数が違うと、Runの前に赤いエラーで気付ける（STEP 8 練習3）。

もしキーを定数にせず、送る側と受け取る側に直接書くと、次のようになります。この枠は入力しません。

import android.content.Context;
import android.content.Intent;
import android.os.Bundle;
import android.util.Log;

import androidx.activity.EdgeToEdge;
import androidx.appcompat.app.AppCompatActivity;
import androidx.core.graphics.Insets;
import androidx.core.view.ViewCompat;
import androidx.core.view.WindowInsetsCompat;

public class TestActivity extends AppCompatActivity {
    private static final String EXTRA_KEY_INT_VALUE = "intValue";
    private static final String EXTRA_KEY_STRING_VALUE = "stringValue";

    @Override

完成版 · TestActivity.java
package jp.ac.jec.a06screentransitionsample;

import android.content.Context;
import android.content.Intent;
import android.os.Bundle;
import android.util.Log;

import androidx.activity.EdgeToEdge;
import androidx.appcompat.app.AppCompatActivity;
import androidx.core.graphics.Insets;
import androidx.core.view.ViewCompat;
import androidx.core.view.WindowInsetsCompat;

import java.util.Arrays;

public class TestActivity extends AppCompatActivity {
    private static final String EXTRA_KEY_INT_VALUE = "intValue";
    private static final String EXTRA_KEY_STRING_VALUE = "stringValue";
    private static final String EXTRA_KEY_STRING_ARRAY_VALUE = "stringArrayValue";

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        EdgeToEdge.enable(this);
        setContentView(R.layout.activity_test);
        ViewCompat.setOnApplyWindowInsetsListener(findViewById(R.id.main), (v, insets) -> {
            Insets systemBars = insets.getInsets(WindowInsetsCompat.Type.systemBars());
            v.setPadding(systemBars.left, systemBars.top, systemBars.right, systemBars.bottom);
            return insets;
        });

        var intValue = getIntent().getIntExtra(EXTRA_KEY_INT_VALUE, 0);
        var stringValue = getIntent().getStringExtra(EXTRA_KEY_STRING_VALUE);
        var stringArrayValue = getIntent().getStringArrayExtra(EXTRA_KEY_STRING_ARRAY_VALUE);
        Log.d("TestActivity", "intValue: " + intValue);
        Log.d("TestActivity", "stringValue: " + stringValue);
        Log.d("TestActivity", "stringArrayValue: " + Arrays.toString(stringArrayValue));
    }

    // startメソッドはAndroid Studioのコードテンプレートを利用して作成できる！
    static void start(Context context) {
        var intent = new Intent(context, TestActivity.class);
        context.startActivity(intent);
    }

    static void start(Context context, int intValue, String stringValue) {
        var intent = new Intent(context, TestActivity.class);
        intent.putExtra(EXTRA_KEY_INT_VALUE, intValue);
        intent.putExtra(EXTRA_KEY_STRING_VALUE, stringValue);
        context.startActivity(intent);
    }

    static void start(Context context, String[] stringArrayValue) {
        var intent = new Intent(context, TestActivity.class);
        intent.putExtra(EXTRA_KEY_STRING_ARRAY_VALUE, stringArrayValue);
        context.startActivity(intent);
    }
}
