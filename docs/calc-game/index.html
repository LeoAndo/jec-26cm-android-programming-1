STEP 00 · 目安 5分

今日のゴール

A01で学んだ「XMLで画面を作る」「Javaでクリックを処理する」を使い、10から引く計算を10問解くゲームを作ります。問題に答えると次へ進み、最後に正解数と時間を表示します。

START→答えの数字を押す→ 10問回答 →結果を見る→RESET

できるようになること

  1. タイマーを開始・停止・リセットする。
  2. 変数で問題番号・正解数・ゲーム中かどうかを覚える。
  3. 1〜9のボタンで答えを判定し、10問目のあとに結果を出す。

問題に使う数字は1〜9です。同じ数字が続く場合もあります。正解・不正解にかかわらず、1回押すと1問の回答になります。

90分×3コマで進めます

3コマ目STEP 9〜1110問で終了させ、ミニ練習・動作確認・提出を行う。

各コマに再実行と個別確認の時間を含みます。A01のボタン処理を授業内で思い出してから始めます。予習は不要です。

STEP 05 · 目安 25分

開始・停止・リセット

変更するファイル：MainActivity.java

前回の画面をRunして確認してから始めます。onCreate の var btnReset = ...; の下に、次の3つの処理を順番に追加します。

SystemClock のimportは android.os.SystemClock です。

① START：開始する

追加 · onCreateの中
// Startボタンを押下した時の処理
btnStart.setOnClickListener(v -> {
    chronometer.setBase(SystemClock.elapsedRealtime() - elapsedTimeMillis);
    chronometer.start();
    btnStop.setEnabled(true);
    btnStart.setEnabled(false);
    btnReset.setEnabled(false);
    isPlaying = true;
});

② STOP：時間を覚えて止める

追加 · STARTの処理の下
// Stopボタンを押下した時の処理
btnStop.setOnClickListener(v -> {
    chronometer.stop();
    elapsedTimeMillis = SystemClock.elapsedRealtime() - chronometer.getBase();
    btnStop.setEnabled(false);
    btnStart.setEnabled(true);
    btnReset.setEnabled(true);
    isPlaying = false;
});

③ RESET：最初の状態に戻す

追加 · STOPの処理の下
// Resetボタンを押下した時の処理
btnReset.setOnClickListener(v -> {
    chronometer.stop();
    chronometer.setBase(SystemClock.elapsedRealtime());
    btnStop.setEnabled(false);
    btnStart.setEnabled(true);
    btnReset.setEnabled(false);
    txtMessage.setText("");
    elapsedTimeMillis = 0;
    nowNo = 1;
    correctNo = 0;
    answer = 0;
    isPlaying = false;
});

時間をどう計算している？

SystemClock.elapsedRealtime() は端末起動後の経過時間をミリ秒で返します。Chronometer は「現在の値 − 基準の値（base）」を表示します。stop() は表示の更新を止めるので、止めた時点の時間を自分で覚えます。

停止時：経過時間 ＝ 現在 − base再開時：base ＝ 現在 − 保存した経過時間
例（すべてミリ秒）計算結果
基準100,000で開始し、106,000でSTOP106,000 − 100,0006,000ミリ秒（6秒）を保存
しばらく待ち、120,000でSTART120,000 − 6,000baseを114,000に変更し、6秒から再開

1,000ミリ秒が1秒です。setEnabled(true) は押せる状態、setEnabled(false) は押せない状態にします。

Runで確かめる

  1. START → 数秒待つ → STOP。時間が止まります。
  2. 数秒待ってSTART。0からではなく、停止した時間から続きます。
  3. STOP → RESET。表示が00:00に戻ります。

ここではタイマーだけ

問題文の表示と数字の採点は、このあと追加します。ゲーム中はRESETが押せないので、先にSTOPを押します。

仕様の確認：Chronometer、SystemClock（Android公式）。

STEP 06 · 目安 15分

ランダムな問題を作る

変更するファイル：MainActivity.java

出題の処理に startQuestion という名前を付けます。メソッドにすると、STARTしたときと回答したあとから、同じ処理を呼び出せます。

① onCreateの外にメソッドを追加

ファイルの末尾にある2つの } を見つけます。上は onCreate、下は MainActivity を閉じています。その2つの間に追加します。

追加 · onCreateの外、MainActivityの中
/**
 * 問題を開始する
 */
private void startQuestion() {
    var randomNumber = ThreadLocalRandom.current().nextInt(1, 10);
    // var randomNumber = RandomGenerator.getDefault().nextInt(1, 10); // API Level 35から利用可能. OSバージョンの分岐は使わない
    answer = 10 - randomNumber;
    var message = nowNo + "問目: 10 - " + randomNumber + " =";
    txtMessage.setText(message);
}

java.util.concurrent.ThreadLocalRandom をimportします。nextInt(1, 10) は 1以上、10未満の整数を選ぶので、1〜9が出ます。answer = 10 - randomNumber; で答えも1〜9になります。

randomNumber と message は、このメソッド内で使うローカル変数です。answer はあとでクリック処理からも読むためフィールドに保存します。

② STARTから呼び出す

STARTのクリック処理の末尾にある isPlaying = true; の直前に、次の4行を追加します。他のSTARTの行は残します。

追加 · STARTのisPlaying = true;の直前
// 初回開始時だけ問題を作る。STOP後のSTARTでは現在の問題をそのまま再開する
if (answer == 0) {
    startQuestion();
}

answer は、問題を作ったときに答えが入るフィールドです（STEP 04）。0 のままなら、まだ問題を作っていないということなので、新しい問題を出します。STOPで止めたあとのSTARTでは answer が残っているため、同じ問題のままタイマーだけ再開します。

Runで確かめる

STARTを押すと「1問目: 10 - 数字 =」が出ます。数字は画像と違って構いません。

STOPからの再開について

STOPでは問題文を残します。STARTを押すと answer が残っているため、現在の問題を変えずにタイマーだけ再開します。問題番号・正解数・計測時間も引き継ぎます。RESET後のSTARTでは answer == 0 なので、新しい問題を出します。

仕様の確認：ThreadLocalRandom.nextInt（Android公式）。

完成版 · MainActivity.java
package jp.ac.jec.a02calcgame;

import android.os.Bundle;
import android.os.SystemClock;
import android.widget.Button;
import android.widget.Chronometer;
import android.widget.TextView;

import androidx.activity.EdgeToEdge;
import androidx.appcompat.app.AppCompatActivity;
import androidx.core.graphics.Insets;
import androidx.core.view.ViewCompat;
import androidx.core.view.WindowInsetsCompat;

import com.google.android.material.snackbar.Snackbar;

import java.util.concurrent.ThreadLocalRandom;
import java.util.concurrent.TimeUnit;

public class MainActivity extends AppCompatActivity {
    private int nowNo = 1; // 今の問題が何問目かのカウント数
    private int correctNo; // 正解数
    private int answer; // 計算結果の答え
    private long elapsedTimeMillis; // タイマーの経過時間(ms)
    private boolean isPlaying = false; // ゲーム中かどうかのフラグ (Chronometer#mStartedフラグを取得できないため用意)
    private TextView txtMessage; // メッセージの表示欄。onCreate以外のメソッドからも使うためフィールドにする

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        EdgeToEdge.enable(this);
        setContentView(R.layout.activity_main);
        ViewCompat.setOnApplyWindowInsetsListener(findViewById(R.id.main), (v, insets) -> {
            Insets systemBars = insets.getInsets(WindowInsetsCompat.Type.systemBars());
            v.setPadding(systemBars.left, systemBars.top, systemBars.right, systemBars.bottom);
            return insets;
        });

        // Viewのインスタンスを取得する
        var chronometer = (Chronometer) findViewById(R.id.chronometer);
        txtMessage = (TextView) findViewById(R.id.txt_message);
        var btnStart = findViewById(R.id.btn_start);
        var btnStop = findViewById(R.id.btn_stop);
        var btnReset = findViewById(R.id.btn_reset);

        // Startボタンを押下した時の処理
        btnStart.setOnClickListener(v -> {
            chronometer.setBase(SystemClock.elapsedRealtime() - elapsedTimeMillis);
            chronometer.start();
            btnStop.setEnabled(true);
            btnStart.setEnabled(false);
            btnReset.setEnabled(false);
            // 初回開始時だけ問題を作る。STOP後のSTARTでは現在の問題をそのまま再開する
            if (answer == 0) {
                startQuestion();
            }
            isPlaying = true;
        });

        // Stopボタンを押下した時の処理
        btnStop.setOnClickListener(v -> {
            chronometer.stop();
            elapsedTimeMillis = SystemClock.elapsedRealtime() - chronometer.getBase();
            btnStop.setEnabled(false);
            btnStart.setEnabled(true);
            btnReset.setEnabled(true);
            isPlaying = false;
        });

        // Resetボタンを押下した時の処理
        btnReset.setOnClickListener(v -> {
            chronometer.stop();
            chronometer.setBase(SystemClock.elapsedRealtime());
            btnStop.setEnabled(false);
            btnStart.setEnabled(true);
            btnReset.setEnabled(false);
            txtMessage.setText("");
            elapsedTimeMillis = 0;
            nowNo = 1;
            correctNo = 0;
            answer = 0;
            isPlaying = false;
        });

        // 数字ボタンを押下した時の処理
        var numberButtonIds = new int[]{
                R.id.btn1, R.id.btn2, R.id.btn3, R.id.btn4,
                R.id.btn5, R.id.btn6, R.id.btn7, R.id.btn8, R.id.btn9
        };
        for (var id : numberButtonIds) {
            var btn = (Button) findViewById(id);
            btn.setOnClickListener(v -> {
                if (!isPlaying) {
                    Snackbar.make(v, "ゲーム中のみボタンを押せます", Snackbar.LENGTH_SHORT).show();
                    return;
                }
                var number = Integer.parseInt(btn.getText().toString());
                if (number == answer) {
                    correctNo++;
                }
                if (nowNo <= 9) {
                    nowNo++;
                    startQuestion();
                } else {
                    chronometer.stop();
                    elapsedTimeMillis = SystemClock.elapsedRealtime() - chronometer.getBase();
                    var timeSec = TimeUnit.MILLISECONDS.toSeconds(elapsedTimeMillis);
                    var message = correctNo + "問正解しました！時間は" + timeSec + "秒です";
                    txtMessage.setText(message);
                    btnReset.setEnabled(true);
                    btnStart.setEnabled(false);
                    btnStop.setEnabled(false);
                    isPlaying = false;
                }
            });
        }
    }

    /**
     * 問題を開始する
     */
    private void startQuestion() {
        var randomNumber = ThreadLocalRandom.current().nextInt(1, 10);
        // var randomNumber = RandomGenerator.getDefault().nextInt(1, 10); // API Level 35から利用可能. OSバージョンの分岐は使わない
        answer = 10 - randomNumber;
        var message = nowNo + "問目: 10 - " + randomNumber + " =";
        txtMessage.setText(message);
    }
}
