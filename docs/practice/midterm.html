配列（複数の値を並べたもの）から値を1つずつ取り出します。最後のcountはどれですか。

var numbers = new int[]{2, 4, 6};
var count = 0;
for (var number : numbers) {
    count++;
}
  1. 0
  2. 3
  3. 6
  4. 12

正答：3

配列には値が3つあります。count++を3回行うので、countは3になります。値の合計を求める処理ではありません。

E20 · 同じ処理を登録する

buttonsは3つのボタンを入れた配列です。txtMessageは文字の表示欄です。画面を開いて次のコードを実行しました。まだボタンは押していません。正しい説明はどれですか。

for (var button : buttons) {
    button.setOnClickListener(v -> {
        txtMessage.setText("押しました");
    });
}
  1. すぐに押しましたと3回表示する
  2. 最初のボタンにだけ処理を登録する
  3. 3つのボタンを自動で押す
  4. 3つのボタンに処理を登録し、表示はまだ変えない

正答：3つのボタンに処理を登録し、表示はまだ変えない

拡張（かくちょう）for文で3つのボタンに処理を登録します。中のsetTextは、実際にボタンを押したときに実行します。
