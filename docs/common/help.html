困ったとき

コードが赤くなった、アプリが動かない、原因が分からない。
エラーに向き合い、自分で解決するための調べ方をまとめています。

  1. 1. エラーが起きたときの調べ方
  2. 2. 共通資料を活用する

1. エラーが起きたときの調べ方

プログラミングでエラーが出るのは自然なことです。エラーメッセージには「どのファイルの何行目で、何が問題か」が必ず書かれています。焦らずに上から順に確認しましょう。

  1. 各単元の「困ったとき」表を確認する
    教科書の末尾にある「困ったとき」には、その単元でよくある間違いと確認場所がまとまっています。
  2. 最初の赤い行を見る
    エラーが何行も出ているときは、一番上の「最初の赤い行」を直します。最初の1つを直すと、あとのエラーがまとめて消えることがよくあります。
  3. 直前のSTEPと見比べる
    手順を1つ飛ばしていないか、大文字・小文字やスペル（綴り）が教科書と違っていないかを確認します。
  4. 先生に質問するときは
    「STEP番号・編集したファイル・最初の赤い行・押した順番」を伝えると、原因が早く分かります。

2. 共通資料を活用する

エラーの種類に応じて、次の共通資料を参考にしてください。

困っていること参考にする共通資料
赤い文字が出てシンボルが見つからないと言われる共通資料：Auto Import で必要なクラスを読み込めているか確認します。
アプリが起動時に落ちる、実行中にエラーになる共通資料：Logcat で赤いエラーログ（例外）を確認します。
エミュレータが起動しない、動かない共通資料：エミュレータ で再起動や設定を確認します。
画面の余白が消える、キーボードが隠れる共通資料：開発Tips でレイアウトの注意点を確認します。
Android Studioのバージョンが違う共通資料：ちがうAndroid Studioのバージョンで進めるとき を確認します。
