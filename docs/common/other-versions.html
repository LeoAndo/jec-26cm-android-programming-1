はじめに読んでください

学科の方針として、貸与パソコン以外、または学校規定のバージョン以外での動作はサポート対象外です。授業中に質問しても、その場では解決できないことがあります。

このページは「サポート外でも自分の環境で進めたい」という人のための手がかりです。確実に授業についていきたい場合は、規定のバージョンに合わせてください。

1. サポートの範囲

1-1. 対象になるもの・ならないもの

扱い
貸与パソコン＋規定のバージョンサポート対象。教科書のとおりに進みます。
自分のMac、または規定と違うバージョンサポート対象外。このページを手がかりに自分で読み替えます。
Windows授業では使いません。教科書はmacOS前提で書かれています。

サポート対象外の環境で起きた問題は、提出物の評価では考慮されません。提出できなくなりそうなときは、早めに貸与パソコンへ切り替えてください。

3. 読み替えのポイント

3-1. 画面の見た目が違う

Android Studioは版が上がると、ウィンドウの文言や項目の並びが変わることがあります。

合わせ方

スクリーンショットの見た目ではなく、「何を選ぶか」で合わせます。2-2の表の4項目さえ同じなら、画面の並びが違っても同じプロジェクトができます。項目が見つからないときは、ウィンドウ内を探すか、Previous で1つ前に戻って確認します。

テンプレートの名前が変わっている場合は、Views という語が入っているものを選びます。Empty Activity（Viewsが付かないもの）はJetpack Composeという別のしくみで、教科書のXMLと合いません。

3-2. 完成プロジェクトを開くと更新をすすめられる

新しいAndroid Studioで完成プロジェクトZIPを開くと、Android Gradle Pluginのアップグレードをすすめる案内（AGP Upgrade Assistant）が出ることがあります。

授業中は更新しません

更新すると build.gradle.kts などの中身が書き換わり、教科書に載っているコードと差が出ます。案内が出ても閉じてください。完成プロジェクトは「答え合わせ用の見本」なので、そのまま読めれば十分です。

自分で作るプロジェクトのほうは、新しいAndroid Studioが選んだバージョンのままで構いません。教科書が指定しているのは2-2の4項目だけです。

3-3. エミュレータの名前が違う

自分のMacには jec_26cm_android1_Pixel 9a がありません。共通資料：エミュレータの準備とアプリの実行の手順で、同じ設定のものを自分で作ってください。名前は同じにしておくと、教科書の記述をそのまま読めます。

3-4. 自動で作られるコードが違う

プロジェクトを新規作成したときの MainActivity.java の中身は、Android Studioの版によって少し違うことがあります。教科書は次の形を前提にしています。

MainActivity.java · 教科書が前提にしているひな形
ViewCompat.setOnApplyWindowInsetsListener(findViewById(R.id.main), (v, insets) -> {
    Insets systemBars = insets.getInsets(WindowInsetsCompat.Type.systemBars());
    v.setPadding(systemBars.left, systemBars.top, systemBars.right, systemBars.bottom);
    return insets;
});

この部分が無かったり形が違ったりしても、教科書で追加する行だけを自分のコードに足せば動きます。迷ったら、完成プロジェクトの MainActivity.java と見比べてください。

レイアウトの一番外側に android:id="@+id/main" が付いていない場合は、自分で付け足します。教科書のJavaが findViewById(R.id.main) で使っています。

4. それでも合わないとき

4-1. 判断のしかた

状況どうするか
画面の文言が違うだけ3-1のとおり、選ぶ内容で合わせる。
教科書のコードを入れても赤いエラーが消えない各単元の「困ったとき」を見る。それでも直らなければ規定のバージョンに切り替える。
Runできない・ビルドが通らない規定のバージョンに切り替える。環境の違いが原因のことが多く、授業時間内では切り分けられません。
提出期限が近い迷わず貸与パソコンで作り直す。教科書どおりに進めば同じものができます。

4-2. このページで確認できていないこと

未検証です

このページの読み替えは、実際に新しいバージョンのAndroid Studioで試して確かめたものではありません。「こういう違いが出やすい」という一般的な注意点をまとめたものです。書いてあるとおりにしても合わないことがあります。

ちがうバージョンで進めて気づいたことがあれば、先生に知らせてください。次の版でこのページに反映します。そのとき「Android Studioのバージョン」「起きたこと」「教科書のどのSTEPか」の3つを伝えてもらえると助かります。
