Logcatの使い方

アプリの中で何が起きたか、文字の記録で確かめます。

1. Logcatを開く

ログは動作の記録です。Logcat（ログキャット）は、その記録をAndroid Studioで読むための画面です。ここではHelloAndroidを例にします。

  1. 授業のプロジェクトを開き、エミュレータでアプリをRunします。
  2. 上のメニューから View → Tool Windows → Logcat を選びます。
  3. Logcatの端末欄で、アプリを動かしている jec_26cm_android1_Pixel 9a を選びます。

2. 見たいログだけを表示する

Logcatの検索欄の内容を全部選び、次の文字に置き換えます。

Logcatの検索欄 · HelloAndroid用
package:jp.ac.jec.a01helloandroid tag:MainActivity level:DEBUG
検索の部分意味
package:jp.ac.jec.a01helloandroidこのアプリのログを選ぶ。
tag:MainActivityMainActivityという目印を付けたログを選ぶ。
level:DEBUGDebug以上の重要度のログを表示する。Log.d の記録を含む。

別の授業で使う場合は、packageとtagを、そのプロジェクトのものに変えます。

3. 操作の前後を比べる

  1. Logcatにログの表示を一時停止するボタンがある場合は、停止していないことを確認します。
  2. アプリをStopしてからRunし、Hello World! の行を探します。
  3. アプリの変更ボタンを押し、Hello, Android! の行を探します。
  4. メッセージの前後を比べます。時刻や数字は、自分の実行時の値で構いません。
読むところの例 · 時刻などを省いた説明用の表示
MainActivity  D  Hello World!
MainActivity  D  Hello, Android!

成功の目印

起動時とクリック後で、ログの文字が違う。画面の表示文字とログのメッセージが一致する。

ログが流れて見えないときは一時停止して読みます。確認後は再開します。

4. ログが出ないとき

  1. 授業の端末を選んでいるか確認します。
  2. 検索欄をコピーし直します。日本語の全角スペースや、packageの打ち間違いを確認します。
  3. ログの一時停止を解除し、末尾へ移動します。
  4. Javaに Log.d を追加した後、保存してRunしたか確認します。
  5. 起動時のログを探すなら、アプリをStopしてからRunします。クリック後のログなら、ボタンをもう一度押します。

アプリがすぐ閉じるときは、検索欄を package:jp.ac.jec.a01helloandroid level:ERROR に変え、赤いエラーの最初の行を先生に見せます。MainActivityのtagで絞ったままだと、別のtagのエラーは見えません。
