提出用APKの作り方

先生からAPKの提出を指示されたときに使います。授業で作ったアプリを、1つのファイルにまとめます。

1. APKとは

APK（エーピーケー）は、Androidにアプリをインストールするためのファイルです。今回は授業内で動作を確認する debug版 を作ります。

用意するもの

授業のプロジェクト、動作確認が終わったコード、先生が指定した提出先。

  1. プロジェクト名が、提出するアプリのものになっているか確認します。
  2. コードをRunし、その教材の完成チェックを行います。
  3. View → Tool Windows → Build Variants を開き、appの Active Build Variant が debug になっているか確認します。

2. APKを生成（せいせい）する

  1. 上の Build メニューを開きます。
  2. Generate App Bundles or APKs → Generate APKs を選びます。表示が異なるバージョンでは、Build App Bundle(s) / APK(s) → Build APK(s) という名前の場合があります。
  3. 処理が終わるまで待ちます。
  4. 完了通知に locate（場所を開く）があればクリックします。

Runを押す操作とは別です

提出するときは、このメニューからAPKを作ります。項目が見つからない場合は、メニューを開いたまま先生に見せてください。

教員と一緒に：メニューが見つからない場合

プロジェクト直下のTerminalで、次のコマンドでもdebug APKを作れます。実行する場所に gradlew があることを確認します。

Terminal · プロジェクト直下
./gradlew :app:assembleDebug

BUILD SUCCESSFUL を確認します。

3. ファイルを見つける

Finderで 書類（Documents） → Android1 → 提出するプロジェクト名 の順に開き、app → build → outputs → apk → debug の順に進みます。

HelloAndroidの場合の保存場所
A01HelloAndroid/app/build/outputs/apk/debug/app-debug.apk
  1. app-debug.apk があることを確認します。
  2. Finderの更新日時を見て、今作ったファイルか確認します。
  3. 提出用のフォルダにコピーします。元の場所のファイルは残します。
  4. 提出するファイル名を 学籍番号_プロジェクト名.apk にします。HelloAndroidでは 自分の学籍番号_A01HelloAndroid.apk です。「自分の学籍番号」を実際の番号に置き換え、区切りには半角の _ を使います。.apk の部分は残します。

4. 提出を確認する

  1. 先生が指定した提出先にAPKをアップロードします。
  2. 提出先で、ファイル名と提出完了の表示を確認します。
  3. 修正したときは、動作確認 → APK生成 → 再提出の順でやり直します。

成功の目印

今日作った .apk が提出先に表示され、学籍番号_プロジェクト名.apk の名前になっている。

このHTML教材のチェック欄だけでは、提出は完了しません。
