# 用語集：简体中文（zh-Hans）

全言語の規則は `skills/translate-teaching-materials/SKILL.md` に従う。授業で使う日本語と画面の表示名を保持し、本文は中国大陸の簡体字で書く。

## 書き方の決まり

- 中国語の引用符は “…”、句読点は「，。；：」、括弧は「（）」を使う。日本語の実画面ラベルは「」で囲み、意味を中国語の括弧で毎回添える。
- 手順は「点击…」「选择…」のように動作を直接書く。チェック欄は「已…」「能够…」で書き、成功の目印は現在の状態を示す。
- 繁体字や香港語彙の「程式」「檔案」「螢幕」は使わない。程序、文件、屏幕を使う。
- **「画面」は屏幕と界面を使い分ける。** 端末やPCのディスプレイそのものは屏幕、アプリのUIとしての画面は界面にする。詳しくは下の「画面の訳し分け」を見る。
- Android Studioの英語表示、コード、パス、単元名、指定AVD名は保持する。macOSの日本語表示とアプリの日本語入力例は原文を残して意味を添える。
- 用語表の用語は「原文（読み） — 中国語」で書く。英字の用語と読み方欄は原文の読みを保持する。本文の漢字用語の定義では日本語と読みを添える。
- 穴埋めの `＿＿` は `____` と書く。

## 画面の訳し分け

日本語の「画面」は、指しているものによって屏幕と界面に分かれる。決められないときは訳を1つに決めず、PR本文に挙げてオーナーに確かめる。

| 指しているもの | 訳 | 例 |
| --- | --- | --- |
| 端末やPCのディスプレイそのもの | 屏幕 | 画面に入りきらない（无法在屏幕中全部显示）、画面の下からはみ出す、画面を先生に見せる、端末の画面が黒い、画面をドラッグする、画面の端から内側へのスワイプ |
| 学生が作るアプリの画面（Activity） | 界面 | 画面を作る（制作界面）、TOP画面（TOP界面）、2つ目の画面を追加する、画面を切り替える、この画面（Activity）、画面の部品（界面上的控件） |
| Android StudioやmacOSなど、PC側アプリのUI | 界面 | Welcome画面（Welcome界面）、プロジェクト画面（项目界面）、New Projectの設定画面（设置界面）、端末を管理する画面（管理设备的界面） |
| 名前のある領域が画面のどこに出るか | 界面 | 画面上部に出すActionBar（界面顶部）、TOP画面の上に置くタイトル画像（TOP界面上方）、画面の上に出るSync Nowの帯（界面顶部）、画面下のビルドの表示（界面下方） |
| 端末のディスプレイ上の見え方・位置 | 屏幕 | 画面の中央にボタンが縦に並ぶ（屏幕中央）、画面の下にSnackbarが出る（屏幕下方）、画面の端の余白（屏幕边缘）、画面下の横棒（屏幕底部的横条）、キーボードが画面の下から出る |

下の2行は、どちらとも取れることがある。**「画面の上／下／中央」という位置の言い方は、迷ったら屏幕にして、判断をPR本文に挙げる。** 迷った例の一覧は issue #268 にある。

次の言い方は中国語として語が決まっているので、意味にかかわらずそのまま使う。

| 日本語 | 訳 |
| --- | --- |
| ホーム画面 | 主屏幕 |
| 画面回転・画面を回す | 屏幕旋转 / 旋转屏幕 |
| 画面読み上げ（スクリーンリーダー） | 屏幕朗读 |
| ロック画面 | 锁屏 |
| 全画面 | 全屏 |
| 画面の案内に従う | 按照屏幕提示操作 |
