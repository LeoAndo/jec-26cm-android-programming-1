# 用語集：Français（fr）

共通ルールは `skills/translate-teaching-materials/SKILL.md` に従う。

## 書き方の決まり

- 学生への呼びかけは vous。操作手順は二人称複数の命令形（Cliquez、Ouvrez、Vérifiez）。
- 引用符は `« … »`。画面に出る日本語は「」と原文を残し、フランス語の意味を丸かっこで添える。
- 句読点は `. , : ; ! ?`、かっこは `(…)`。引用符内側と `: ; ! ?` の前にはスペースを置く。アポストロフィは直線の `'`。
- 見出しは先頭語だけ大文字。英字の飾り見出し、STEP番号、単元名は原文を保つ。
- チェック欄の「〜できた」は一人称の複合過去（J'ai …）。成功の目印は現在形の平叙文。
- 用語表は日本語と読みを残し、` — ` の後に訳を添える。本文で和語を定義する文にも日本語と読みを添える。
- Android Studioの表示は英語のまま。macOSの日本語表示には日本語を残してフランス語を添える。
- 穴埋めの `＿＿` は `____`。
